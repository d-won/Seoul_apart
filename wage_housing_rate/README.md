# 시간당 임금 · 서울 아파트 실거래가 · 정책금리 (2005–2025)

최근 20여 년(**2005–2025**) 동안 세 지표가 어떻게 움직였는지 라인 차트로 비교합니다.

1. **시간당 명목임금** — 원/시간
2. **서울 아파트 실거래가** — 억 원 (평균 매매가격) + 실거래가격지수
3. **정책금리** — 한국은행 기준금리(%, 연말)

단위가 완전히 다르므로 **이중 축을 쓰지 않고**, ① 각 지표를 고유 단위로 보여주는
3단 패널과 ② 임금·아파트값을 같은 출발선(2005년=100)에 놓은 지수 비교로 나눠 그립니다.

> **월별/최신치**: 정책금리는 변경 이력으로 구성한 **실제 월별** 시계열(2026.07 = 2.75%까지)로 그립니다.
> 임금·아파트도 원래 월별 공식통계가 있으나(사업체노동력조사 월별 임금, 한국부동산원 월별 실거래가격지수),
> 이 환경의 포털 접속 차단으로 월별 원자료를 못 받아 확보된 연간·앵커값(최신 2025년)으로 표시했습니다.
> 월별 정밀 시계열은 `src/fetch_live.py`(ECOS·KOSIS 키)로 받을 수 있습니다.

## 한눈에 보기

- 임금은 20여 년간 **약 +178%**(지수 278), 서울 아파트 평균가는 **약 +278%**(지수 378)로,
  2015년 이후 아파트값이 임금을 앞질렀고 **2025년 다시 급등**해 격차가 크게 벌어졌습니다.
- 정책금리는 2007년 5.00% 고점 → 2020년 0.50% 저점 → 2023년 3.50% → 2025년 2.50%로,
  저금리기(2015–2021)와 아파트값 급등이 겹칩니다.
- 2026년(진행 중): 기준금리 7월 **2.75%로 인상**, 서울 집값 상승세 지속. 임금 6월 조사값은
  미발표라 연간값이 완성된 **2025년까지** 표시합니다.

## 실행

```bash
pip install -r requirements.txt
python build_charts.py        # outputs/ 에 PNG 2종 생성
```

산출물
- `outputs/three_indicators.png` — 3단 패널(임금 / 아파트값 / 금리)
- `outputs/wage_vs_apartment_index.png` — 2005=100 지수 비교
- `chart.html` — 인터랙티브 버전(호버 툴팁·다크모드·데이터 표). 브라우저로 바로 열기.

> 한글 라벨을 위해 나눔고딕 등 한글 폰트 설치를 권장합니다(없으면 자동 영문 폴백).
> `sudo apt-get install fonts-nanum` 후 matplotlib 폰트 캐시가 갱신됩니다.

## 데이터와 신뢰도 (반드시 확인)

`data/` 의 CSV는 각 값에 **신뢰도 표기**(official/confirmed vs estimate)를 담고 있습니다.

- **정책금리**: 한국은행 기준금리 결정 이력 — 전 구간 확정(2025년말 2.50%, 2026.07 2.75% 인상).
- **시간당 임금**: **2018–2025년 공식 수치**(고용형태별근로실태조사·사업체노동력조사, 매년 6월),
  2005–2017년은 확인된 앵커 기반 후방외삽 **추정치**. 2020년 표준산업분류 개편으로
  2019년 이전과 계열 단절이 있습니다. 2026년 6월 조사값은 아직 미발표.
- **서울 아파트값**: KB 평균 매매가격(감정시세 평균이라 엄밀한 '실거래'는 아님, 실거래 흐름의 근사).
  주요 앵커(2018 8억, 2020 10억, 2025.07 14.06억, 2025.12 15.08억) 확인, 앵커 사이는 추세 보간.

### 정확한 공식 수치로 갱신하기

이 리포지토리를 만든 환경에서는 한국 통계포털 접속이 네트워크 정책상 차단되어
원자료 표를 직접 받지 못했습니다. **외부망이 열린 로컬에서** API 키를 넣어 갱신하세요.

```bash
export ECOS_API_KEY=...    # 한국은행 ECOS  https://ecos.bok.or.kr/api
export KOSIS_API_KEY=...   # 국가통계포털   https://kosis.kr/openapi
python src/fetch_live.py
```

관련 통계표
- 임금: KOSIS `DT_118N_LCE0001`(고용형태별), `DT_118N_MON051`(산업·규모별)
- 아파트 실거래가지수: KOSIS `DT_KAB_11672_S1` / 한국부동산원 공동주택 실거래가격지수
- 기준금리: ECOS `722Y001`
