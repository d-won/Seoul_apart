# 방법론: 재개발 인근 구축 아파트 가격 파급효과 분석

> 질문: **"서울에서 재개발된 지역 주변의 구축 아파트는 얼마나 올랐나? 재개발되지 않았어도
> 인근에 있으면 그 영향(파급효과)을 받는가?"**

이 문서는 그 질문에 답하기 위한 데이터·지표·측정 설계를 설명합니다.

---

## 1. 데이터

- **원천**: 국토교통부 실거래가 공개시스템 — 아파트 매매 실거래가 상세 자료
  (`RTMSDataSvcAptTradeDev`, 공공데이터포털 오픈API).
- **단위**: 개별 매매 계약 1건 = 1행. 아파트명·전용면적·계약년월·거래금액·건축년도·법정동·층 등.
- **범위**: `config/redevelopment_areas.yaml` 에 정의된 재개발 구역이 속한 자치구,
  기본 2015-01 ~ 현재(약 10년).
- **한계**: API 응답에 **위경도가 없음** → 거리 계산을 위해 아파트 좌표를 별도 확보해야 함
  (`config/apartment_coords.yaml` 수동 등록 또는 지오코딩).

## 2. 핵심 지표: 평단가 중앙값

- 거래금액(만원) ÷ 전용면적(㎡) × 3.3058 = **평단가(만원/3.3㎡)**.
  단순 거래금액은 평형 구성에 좌우되므로 면적으로 정규화한 평단가를 쓴다.
- 월별 **중앙값(median)** 을 시세 대용치로 사용. 평균 대비 특이 고가/저가 거래와
  평형 믹스 변화에 덜 흔들린다.
- 이상치 처리: 전용면적 20~300㎡ 로 제한, 평단가 상·하위 1% winsorize,
  계약 해제(`cdealType='O'`) 건 제외.

## 3. "구축" 정의

- **거래 시점 기준 준공 후 경과연수 ≥ 15년**(`old_apartment_min_age`) 이면 구축으로 간주.
  = `거래연도 − 건축년도 ≥ 15`. 재건축된 신축 단지가 아닌, **기존에 서 있던 아파트**를
  분리해 "재개발 수혜가 아니라 파급효과를 받은 대상"을 관찰하기 위함.

## 4. 두 가지 측정 방법 (결합)

재개발 근접효과를 **공간(거리)** 과 **시간(이벤트)** 양쪽에서 본다.

### (A) 거리 구간 비교 — "가까울수록 더 올랐는가?"

1. 각 구축 거래 아파트를 가장 가까운 재개발 구역 중심과 **haversine 거리**로 잰다.
2. 거리 구간으로 분류: `0–500m / 500–1000m / 1000–2000m / 2000m+`
   (경계는 `distance_bands_m` 로 조정).
3. 구간별 월별 평단가 중앙값 추이와 **전체 기간 상승률**을 비교.
4. 해석: `0–500m` 상승률이 `2000m+`(대조군)보다 높으면 → **거리 프리미엄 존재**.

`2000m+` 구간은 같은 자치구의 광역 시장 흐름을 대표하는 **대조군** 역할을 한다.
"재개발과 무관한 동네도 이만큼은 올랐다"는 기준선.

### (B) 이벤트 스터디 + 간이 DID — "언제부터, 재개발 때문에 올랐는가?"

거리만 보면 "원래 비싼 동네라 더 오른 것"과 구분이 안 된다. 그래서 **시점**을 맞춘다.

1. 각 구역의 기준 이벤트월을 **t=0** 으로 정렬. 기본 이벤트는 **관리처분인가**
   (`event_key`) — 재개발 실현이 사실상 확정되어 시장이 반응하는 분기점.
   (`designation`/`construction`/`occupancy` 로 변경 가능.)
2. 각 구역의 인근 구축 평단가를 **t=0 = 100** 으로 정규화한 지수를 만든다.
3. **근거리(treated, 0–500m)** 와 **원거리(control, 2000m+)** 의 상대월별 평균 지수를 겹쳐 그린다.
4. **간이 이중차분(DID)**: `(근거리 사후 상승 − 원거리 사후 상승)`.
   - 이벤트 *이전* 두 선이 나란히 움직이다가(공통추세),
   - 이벤트 *이후* 근거리만 위로 벌어지면 → 그 벌어진 폭이 **재개발 근접 프리미엄**.

## 6. 해석 시 유의점 (인과 해석의 한계)

- 이 설계는 **준실험(quasi-experimental)** 이다. 엄밀한 인과 추정은 아니며,
  다음 교란요인이 남는다:
  - **역방향/선택**: 원래 오를 동네라 재개발이 추진됐을 수 있음.
  - **동시 사건**: 지하철 개통, 학군, 광역 정책(대출규제 등)이 같은 시기에 작용.
  - **좌표 커버리지**: 좌표 미등록 단지는 거리 분석에서 빠져 표본 편의 가능.
  - **미입주 구역**(한남·노량진·반포주공1 등)은 매매 실거래가 적어 별도 취급 필요.
- 더 엄밀히 하려면: 단지 고정효과 패널 회귀, 성향점수 매칭, 공통추세 검정(pre-trend),
  플라시보 이벤트월 검정 등을 추가 권장.

## 7. 재현 방법

```bash
pip install -r requirements.txt

python run.py selftest        # (선택) API 없이 로직 점검
python run.py all --start 201501 --end 202506
```
